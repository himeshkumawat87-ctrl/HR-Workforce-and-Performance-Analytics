# HR-Workforce-and-Performance-Analytics
An HR analytics project focused on workforce distribution, salary analysis, employee performance, and hiring trends using Python, SQL, and Power BI.
# HR Workforce and Performance Analytics

## 1. Project Overview

The HR Workforce and Performance Analytics project focuses on analyzing employee information, workforce distribution, salary and compensation, departmental performance, employee demographics, and hiring trends.

The project aims to present HR data in an understandable format using data analytics tools and interactive Power BI dashboards.

## 2. Project Objectives

- Analyze employee information and workforce distribution.
- Examine employee salaries and compensation.
- Compare workforce distribution across departments and locations.
- Analyze employee performance ratings and bonuses.
- Understand employee demographic patterns.
- Explore hiring trends over time.
- Present HR metrics through interactive dashboards.

## 3. Dataset Description

The project includes four datasets:

- emp_info.csv: Employee information.
- emp_salary.csv: Salary, deductions, performance ratings, and bonuses.
- department.csv: Department information.
- job_roles.csv: Job role information.

## 4. Tools and Technologies

- Python
- Pandas
- SQL
- Microsoft Power BI

## 5. Project Workflow

1. Load and inspect the datasets.
2. Check data quality and missing values.
3. Prepare and combine relevant datasets.
4. Create calculated columns and measures where required.
5. Analyze workforce, salary, and performance information.
6. Create interactive Power BI dashboards.
7. Document findings and limitations.

## 6. Power BI Dashboard

The project contains six dashboard pages:

1. HR Workforce Overview
2. Department Performance
3. Salary and Compensation Analysis
4. Performance Analysis
5. Workforce Demographics
6. Hiring and Workforce Trends

## 7. Key Findings

The current workforce overview dashboard shows:

- Approximately 10,000 employees.
- 9 departments.
- 16 job roles.
- An average basic salary of approximately 79.03K.
- An average performance rating of 3.78.
- Approximately 84.88% of employees marked as active.
- Approximately 15.12% of employees marked as inactive.
- A nearly balanced gender distribution, with 50.17% female and 49.83% male employees.

These findings are based on the current Power BI workforce overview dashboard.

## 8. Limitations

The analysis is limited to the information available in the provided datasets. Additional information, such as attendance, employee satisfaction, and exit records, may be required for more detailed HR analysis.

## 9. Conclusion

This project demonstrates how HR data can be organized, analyzed, and presented through dashboards. The results help users explore workforce distribution, salary metrics, employee performance, and hiring trends.
